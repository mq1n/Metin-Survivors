# Metin Survivors

> Free-to-play 3D browser action roguelite (survivors-like) playable instantly with zero install on desktop and mobile browsers (WebGL2). Supports solo runs and real-time 1–4 player online co-op, cloud save sync, global leaderboards, and full Turkish (`tr`) + English (`en`) localization.

- **Play Online:** https://metin-survivors.com/
- **Genre:** 3D Action Roguelite / Survivors-like / Hack-and-Slash / Online Co-op
- **Platform:** Desktop & Mobile Web Browsers (WebGL2, Three.js, PWA-installable)
- **Pricing:** Free-to-play (zero install, no mandatory login)
- **Languages:** Turkish (`tr`), English (`en`)

## Game Content

### 5 Hero Classes & 10 Doctrines
1. **Warrior / Savaşçı** — Sinew (`Kuvvet`), Spirit (`Ruh`)
2. **Ninja** — Silent Edge (`Sessiz Bıçak`), Quiver (`Sadak`)
3. **Yacha** — Spellsteel (`Büyü Çeliği`), Hexcraft (`Lanet Sanatı`)
4. **Shaman / Şaman** — Talisman (`Tılsım`), Stormbalm (`Bora Merhemi`)
5. **Wolfman** — Redmane (`Kızıl Yele`), Moonmane (`Ay Yelesi`)

### 4 World Zones
1. **Yeonmu Plains (`Yeonmu Ovası`)**
2. **Suryeon Valley (`Suryeon Vadisi`)**
3. **Mount Seori (`Seori Dağı`)**
4. **Daeryeol (`Daeryeol`)**

### Core Features
- **20 Bosses & 114 Skills** with manual aim/casting or optional auto-combat toggles
- **1–4 Player Online Co-op** via shareable room codes with dedicated co-op leaderboards
- **Roguelite Meta-Progression:** Talents (`Yetenekler`), Armory (`Cephanelik`), Blacksmith (`Demirci`), Collection (`Koleksiyon`), and Codex (`Kodeks`)
- **Cloud Save & Global Leaderboards:** Solo, Co-op, Weekly, Daily, and Per-Class boards
