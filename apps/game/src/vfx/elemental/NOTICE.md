# elemental/ — third-party provenance

Techniques, shader code and geometry generators in this directory are ported (JS → strict TypeScript, settings trees replaced
by typed constants, editor/UI/aim/input code dropped) from **Elemental Sandbox / threejs-vfx**
(https://github.com/majidmanzarpour/threejs-vfx), MIT, © 2026 mohamedachrefelouafi. The license text is kept verbatim in
`LICENSE` next to this file. None of the repository's HDR probe, FBX or character assets are used.

Every ported file starts with a header naming its source file in that repository.
